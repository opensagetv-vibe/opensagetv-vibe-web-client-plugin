# Contributing

Keep changes stock-SageTV-compatible and scoped. Run `dev.cmd all` on Windows
or `./dev.sh all` on Linux before review, update `CHANGELOG.md`, `HANDOFF.md`,
and `TASKS.md`, and record which results are generated versus physical.

Do not commit credentials, diagnostic bundles, recordings, cached vendor
assets, FFmpeg/MIM binaries, or generated build output.
