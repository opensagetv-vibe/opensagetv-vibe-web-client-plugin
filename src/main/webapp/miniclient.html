MiniClient settings


      

        Streaming and transcoding
        
Vibe Android-style controls, adapted for browser playback. Settings belong to this browser, not to global SageTV or MIM configuration.

        
Player and video
          
          
          
          
          
          
          
          
          
          
          
          
Bitrate is a target, not an exact measured rate. Encoder and video bitrate apply only when video is transcoded. Copy keeps the source video codec and remuxes/resegments it without video encoding. With Copy, Automatic fallback may restart as H.264 if the browser advances playback but produces no video frames. Copy requires Source resolution/FPS and Deinterlace Auto/Off.

        

        
Audio
          
          
          
          
          
          
          
          
Positive delay plays audio later. Delay range is -4000..+4000 ms in 25 ms steps. Track index is session-only; a new recording returns to language/automatic selection. Commentary/audio-description tracks are deprioritized unless explicitly selected. Browser output has no AudioTrack/HDMI passthrough control; changing track/delay/quality restarts only the media stream at the same reported position.

        

        
Broadcast captions (local browser)
          
          

          
Effective caption source: Off

          
          
          
          
          
          
          
          
          
          
CEA is extracted from original compressed video. DVB Teletext is decoded from the original transport stream before video encoding, so QSV/NVENC/VAAPI/software transcoding does not need to preserve Teletext packets. Teletext here is the Level-1 subtitle-page subset, not an interactive Teletext browser. DVB bitmap is decoded independently to an RGBA overlay and stays outside the video encoder. PGS/DVD bitmap and ordinary file subtitles remain later phases.

        


        
Ordinary subtitles (file / embedded)
          
          
          
          
          
          
Independent of Broadcast captions. Text uses sanitized browser text cues. PGS and DVD/VobSub bitmap tracks are adapted through FFmpeg to the local bitmap decoder; VobSub requires palette context from the container or an associated IDX file. ASS/SSA advanced styling is flattened.

Playback starts from a small buffer, then continues filling the selected forward reserve. HLS reserve changes apply immediately; MPEG-TS buffer changes apply on the next recording/seek or Apply now. Startup-segment choices apply only to HLS; MPEG-TS starts on available decodable data. Browser memory may reduce the achievable reserve. Native Safari controls its own buffer.

      
      
      
      
      
Automatic asks SageTV to lay out the UI for the available window. Fixed resolutions fit the whole picture without cropping. A ?ui=WIDTHxHEIGHT URL overrides this setting. Video aspect is separate.

      
      
      
Fill browser removes added bars while preserving aspect, so edges may be cropped on a differently shaped window. Fit shows every source edge with bars as needed. Stretch shows every edge without bars, but changes proportions. Black bars encoded in the recording are part of the video; this setting does not detect/remove those.
